Activities Completed

- Analysed a network connectivity scenario involving successful ping responses but failed DNS queries.
- Identified DNS resolution failure as the likely issue.
- Discussed checking DNS server configuration and availability.
- Reviewed the use of "ping", "nslookup", and "ipconfig /all" in network troubleshooting.

Key Takeaways

Successful communication with an external IP address does not necessarily mean DNS is functioning correctly. An unavailable or incorrectly configured DNS server can prevent domain names from resolving.

Reflection

This exercise improved my understanding of how to distinguish between basic network connectivity problems and DNS-related issues.
