Day 11: Network Configuration and Connectivity Testing

Date: October 29, 2026
Journey: 60 Days of Cybersecurity

Focus

Hands-on networking lab using Windows Command Prompt.

Objective

Inspect network configuration and test local and external network connectivity.

Activities Completed

- Used "ipconfig" to identify IPv4 address, subnet mask and default gateway.
- Tested the local TCP/IP stack using "ping 127.0.0.1".
- Tested communication with the default gateway.
- Checked external IP connectivity using "ping 8.8.8.8".
- Tested DNS resolution using "nslookup google.com".

Key Takeaways

Connectivity tests help identify where a network problem may exist. Testing an IP address directly helps distinguish basic IP connectivity from DNS resolution issues.

Reflection

All connectivity tests returned successful results. I improved my understanding of network configuration, troubleshooting commands and how to interpret their results.

Next Steps
