Day 4: Network Security and SOC Incident Response

Date: October 22, 2026
Journey: 60 Days of Cybersecurity
Focus: Firewall Fundamentals, Network Segmentation, and Incident Response

Learning Objectives

- Understand how firewall rules control network traffic.
- Explain how network segmentation improves security.
- Apply security concepts to a simulated SOC scenario.
- Develop analytical thinking when investigating potential security incidents.

What I Learned

1. Firewall Fundamentals

I learned how firewalls use configured rules to determine which network traffic should be allowed or blocked.

Key takeaways:

- Approved traffic can be permitted according to defined rules.
- Unauthorized connections can be blocked.
- Controlling outgoing traffic is also important because compromised systems may communicate with malicious destinations or transmit sensitive information.

2. Network Segmentation

I explored how organizations divide networks into separate segments to protect sensitive systems and control communication.

Using a hypothetical company network containing HR, Finance, guest Wi-Fi, and a public-facing web server, I identified why these systems require appropriate separation and access restrictions.

Key takeaways:

- Sensitive systems need appropriate access controls.
- Guest networks should be separated from internal business systems.
- Segmentation can limit lateral movement if an attacker compromises a system.
- Communication between network segments should be controlled rather than automatically permitted.

3. SOC Incident Response

I analysed a simulated security alert involving a public-facing web server attempting to establish unusual connections to a Finance computer.

I considered the potential threat, relevant security controls, evidence to investigate, and possible containment measures.

Key takeaways:

- An alert indicates something that needs investigation; it does not automatically prove malicious activity.
- Investigations should consider IP addresses, ports, timestamps, firewall logs, web server logs, and endpoint security alerts.
- If a server is confirmed compromised, restricting its communications can help prevent further harm.
- Protecting affected systems, preserving evidence, and escalating the incident are important response activities.

Practical Exercise

I completed three scenario-based exercises covering:

1. Interpreting firewall rules.
2. Identifying network segmentation requirements.
3. Analysing a potential security incident from a SOC analyst's perspective.

These exercises helped me practise applying security concepts to realistic situations.

Reflection

The most important thing I learned today was how to think more like a cybersecurity analyst. Rather than simply identifying a possible threat, I practised considering the risks, investigating relevant evidence, and selecting appropriate security responses.

Incident response was the most challenging topic for me. I want to improve my ability to determine the right containment actions and distinguish between different types of network traffic.

I have a good understanding of the concepts covered, but I recognise that incident response requires further study and practical experience.
