Day 2: Hands-on Networking Practice

Date: October 20, 2026
Journey: 60 Days of Cybersecurity
Focus: Networking Fundamentals and Command-Line Tools

Objective

To gain practical experience using basic Windows networking commands and understand how they help troubleshoot network connectivity and DNS resolution.

Practical Exercises

1. Inspecting Network Configuration with "ipconfig"

I ran "ipconfig" in Windows Command Prompt for the first time.

I identified the following network configuration fields:

- IPv4 Address
- Subnet Mask
- Default Gateway

What I learned: These fields provide information about my computer's network configuration and how it communicates with other networks.

2. Testing Connectivity with "ping"

I ran "ping google.com" and received successful replies.

What I learned: The "ping" command uses ICMP echo requests and replies to test whether a destination responds over the network. However, a successful ping does not guarantee that every service on the destination is working.

3. Investigating DNS with "nslookup"

I ran "nslookup google.com" and observed IPv4 and IPv6 addresses in the results.

What I learned: DNS helps translate domain names into IP addresses. The "nslookup" command allows me to investigate DNS resolution.

4. Understanding IPv4 and IPv6

I learned to distinguish between the two address formats:

- IPv4 uses 32-bit addresses written in dotted-decimal notation.
- IPv6 uses 128-bit addresses written in colon-separated hexadecimal notation.

5. Troubleshooting Scenario

I considered a scenario in which DNS successfully resolves a domain name, but the website fails to load.

I correctly identified that DNS resolution can succeed while another issue prevents access to the website.

Key Takeaways

- Network troubleshooting requires testing different aspects of connectivity.
- Successful DNS resolution does not guarantee that a website is accessible.
- IPv4 and IPv6 use different address formats.
- Basic command-line tools are useful for investigating network behaviour.

Reflection

This was my first time running "ipconfig", "ping", and "nslookup" myself. The exercise helped me connect networking concepts with practical commands on a Windows computer.
