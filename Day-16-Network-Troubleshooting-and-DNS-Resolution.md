Activities Completed

- Investigated a hostname resolution error caused by an unavailable internet connection.
- Reviewed the difference between network connectivity testing and DNS resolution.
- Worked through a troubleshooting scenario involving successful router connectivity but failed DNS resolution.
- Analysed how successful communication with an external IP address alongside failed DNS resolution can indicate a DNS-related problem.

Key Takeaways

"ping" tests reachability, while "tracert" helps examine the route to a destination. DNS translates domain names into IP addresses. Successful communication with an external IP address alongside failed DNS resolution suggests that DNS configuration or service availability should be investigated.
