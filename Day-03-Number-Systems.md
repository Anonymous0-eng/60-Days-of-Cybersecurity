What I Learned

1. Binary to decimal conversion: Binary numbers use only 0 and 1. Each position represents a power of 2, allowing binary values to be converted into decimal numbers.
2. Decimal to binary conversion: Decimal numbers can be represented in binary using combinations of 0s and 1s.
3. Hexadecimal numbers: The hexadecimal system uses digits 0–9 and letters A–F. It provides a compact, readable way to represent binary values.
4. Number systems in networking: Understanding binary and hexadecimal helps explain how network addresses and other technical values are represented.
5. IPv4 octets: Each IPv4 address contains four octets. An octet consists of 8 bits and can represent decimal values from 0 to 255.
